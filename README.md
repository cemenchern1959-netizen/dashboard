# 🖥️ Start Dashboard

Минималистичная стартовая страница-дашборд в чёрно-бордовом стиле (`#000000` + `#800020`) с быстрым поиском, закрепами и переключением языка между русским и английским.

Работает в одном автономном HTML-файле без установки зависимостей и сторонних библиотек.

---

## ✨ Возможности

- **🕒 Системные часы и дата:** отображает текущее время и дату по настройкам устройства, подстраивая формат даты под выбранный язык.
- **🔍 Быстрый поиск:** строка поиска по центру для мгновенных запросов в Google.
- **📌 Закреплённые ссылки:**
  - **Wikipedia (EN)** — быстрый переход к англоязычной Википедии.
  - **YouTube** — открывает главную страницу YouTube.
  - **Скачать другие проекты** — открывает окно со ссылками на репозитории `winiso_downloader` и `vertical_desk_surfacego`.
- **🌐 Локализация (`RU / EN`):** переключатель языка в правом верхнем углу с сохранением выбора в `localStorage`.

---

## 🚀 Как запустить

1. Скачай файл `index.html` из репозитория.
2. Открой его в любом браузере двойным кликом.
3. При необходимости нажми **F11** для полноэкранного режима.

---

## 🎨 Оформление

- **Цветовая схема:** глубокий чёрный фон (`#000000`), тёмные карточки и бордовые акценты (`#800020`).
- **Один файл:** весь интерфейс, стили и логика находятся внутри `index.html`.
